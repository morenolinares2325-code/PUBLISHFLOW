# 🚀 PublishFlow

## Tu Departamento de Publicidad Digital

PublishFlow es una plataforma SaaS desarrollada en Streamlit que permite a empresas, autónomos y profesionales gestionar campañas publicitarias desde un único panel.

La filosofía del proyecto no es ofrecer una simple herramienta de generación de contenido, sino proporcionar la experiencia de trabajar con un **Departamento de Publicidad Digital completo**.

---

# 🎯 Visión

PublishFlow no se presenta como:

❌ Generador de publicaciones IA

❌ Programador de redes sociales

❌ Herramienta de marketing convencional

PublishFlow se presenta como:

> Tu Departamento de Publicidad Digital.
>
> Un equipo especializado analiza tu negocio, diseña la estrategia, redacta los contenidos y organiza la difusión multicanal desde una única plataforma.

# 💾 Persistencia

Las campañas se almacenan actualmente mediante JSON local.

Archivo:

```text
data/campanas.json
```

Ejemplo:

```json
{
  "nombre": "Lanzamiento Fibra Óptica",
  "descripcion": "Promoción local de fibra",
  "objetivo": "Conseguir Clientes",
  "pais": "España",
  "ciudad": "Madrid",
  "web": "https://ejemplo.com",
  "canales": [
    "Facebook Pages",
    "Instagram Business"
  ],
  "fecha": "01/10/2026 12:30"
}
```
